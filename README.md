# 🧠 Memory Card Game

A fun and interactive memory card game built using **HTML**, **CSS**, and **JavaScript**. Flip cards, test your memory, and match all pairs with the fewest moves possible!

## 🎮 Features

- 🔄 Card flipping animation
- 🧩 Match detection logic
- ⏱️ Move counter and timer
- 📱 Responsive design for mobile and desktop
- 🔁 Restart button to play again

## 📦 Tech Stack

- **HTML**: Core structure and layout
- **CSS**: Styling and animations
- **JavaScript** : Game logic

|---------------|-------------|
| `index.html`  | Main html   |
